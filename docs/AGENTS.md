# docs: tài liệu và sổ tiến độ

| File | Khi nào sửa |
|------|-------------|
| `progress.md` | **Cuối mỗi phiên làm việc.** Đây là chỗ phiên sau đọc để làm tiếp (hook in ra khi mở Claude Code) |
| `flows.md` | Đổi luồng nghiệp vụ: sửa sơ đồ Mermaid trong cùng lần sửa code |
| `architecture.md` | Thêm/bỏ thành phần hoặc dịch vụ ngoài |
| `decisions.md` | Ra một quyết định thiết kế mới: thêm mục đánh số tiếp (lý do, cách làm, khi nào xem lại) |

## Cách ghi `progress.md`

- "Đang làm": việc dở dang, file đang sửa, bước tiếp theo cụ thể.
- "Nhật ký": thêm một dòng mới nhất lên đầu: ngày, việc đã xong, test đã chạy và kết quả thật, việc chưa thử được.
- Ngắn, sự thật, không chép lại code. Xong một việc trong "Việc tiếp theo" thì chuyển sang nhật ký.
